# Регулярная практика и учебные материалы

Пользователь поручил добавить календарь, геймификацию, минимум одну новую задачу с понедельника по пятницу, разнообразные примеры и подробные объяснения паттернов. Подтверждено: повторение пройденного не закрывает дневную цель.

## Поведение

- Статический сайт GitHub Pages и существующее оформление Algorithms Lab сохраняются. Данные прогресса хранятся локально в браузере.
- Календарь показывает фактические даты первого закрытия новых задач, запланированные будни и необязательные выходные. Цель — минимум одна новая задача в каждый будний день после начала учёта; задним числом задолженность не создаётся.
- Повторное переключение отметки не создаёт новые события. История первого закрытия сохраняется при снятии отметки для повторного разбора; это объясняется в интерфейсе.
- Сохраняются старые отметки, без присвоения им вымышленных дат. За каждую когда-либо разобранную задачу начисляются 100 XP; уровень растёт через каждые 500 XP. Награды: первая задача, десять задач, пять успешных будней подряд, первый полностью разобранный паттерн.
- Серия учитывает только будни; выходные её не прерывают и не удлиняют. Незавершённый текущий день не сбрасывает серию до его окончания. Календарные даты определяются в локальном часовом поясе устройства.
- Для каждой из 101 задач будет минимум четыре разных проверенных примера с понятными названиями, всего не менее 404. Новые ожидаемые ответы заданы независимо от исполняемого решения.
- Все 19 паттернов получают: интуицию, признаки распознавания, последовательность решения, небольшой разбор, инвариант, ошибки и сравнение с альтернативами.

## Проверка

Изолированные тесты модели прогресса, миграции, границ дат и серий; Python-проверки всех примеров и трасс; браузерные сценарии календаря, сохранения, повторных отметок, всех примеров и мобильной вёрстки. Публикация — существующий workflow GitHub Pages.
