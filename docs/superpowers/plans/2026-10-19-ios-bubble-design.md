# iOS Bubble Design Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking. План одобрен пользователем; реализация и локальная проверка завершены. Публикация остаётся отдельным этапом.

**Goal:** Перенести Algorithms Lab в согласованный мягкий bubble-стиль с компоновкой «Фокус», сохранив учебные возможности и накопленный прогресс.

**Architecture:** Сохранить React, маршруты, генератор занятий и расчёт прогресса. Вынести визуальные токены и оболочку приложения, затем последовательно обновить страницу задачи, сцены и календарь. Переносить композицию из макета, а не демонстрационную логику и данные.

**Tech Stack:** Существующие React 19, TypeScript, CSS, Vite, Python-генератор занятий и Playwright. Новые UI-библиотеки для этого объёма не нужны.

**Spec:** Одобренная в переписке концепция: `/Users/grigorijlavrov/.codex/visualizations/2026/10/16/01a142c1-2708-7f10-804f-c7ef8d7afc21/ios-bubble-concept.html`. Рабочее допущение для плана — вариант «Фокус», тёмный вид как основной визуальный ориентир; светлый вид также поддерживается. Работа выполнена по этому направлению; фактические отклонения и проверки описаны в docs/bubble-design-verification.md.

## Global Constraints

- Меняется представление приложения; 19 глав, 101 задача, 404 примера и Python-решения сохраняются.
- Сохраняются маршруты `#/problem/<id>` и `#/calendar`, поиск, фильтр сложности, предыдущая/следующая задача и ссылки на источники.
- Сохраняются ключи `patterns-study-v2`, `patterns-progress`, `patterns-last`, даты первого закрытия и правила миграции.
- Цель — минимум одна новая задача с понедельника по пятницу; повторение не даёт новые XP; выходные добровольные.
- Существующие значения XP, уровней и серий вычисляются прежними функциями из `src/progress.ts`.
- Демо-прогресс, фиктивный профиль GL, подписи «Демо» и упрощённый четырёхшаговый движок из макета в приложение не переносятся.
- Текст интерфейса — русский; код, идентификаторы и существующие технические названия сохраняются.
- Публикация на GitHub Pages — отдельный завершающий этап после просмотра готового локального результата и разрешения на публикацию.

## Review Focus

- Существующий прогресс: после редизайна и переключения темы записи, XP и даты не изменяются.
- Каталог: длинные названия и 101 задача доступны мышью и клавиатурой; закрытие возвращает фокус на кнопку открытия.
- Небольшой экран: при ширине 320 px страница и плеер не выходят за границы; сложная схема прокручивается только внутри своей области.
- Цветовые состояния: текущий узел, посещённый узел, ответ, ошибка и исключённая область различимы в обеих темах и имеют дополнительные обозначения.
- Недоступное хранилище и служебные состояния: приложение открывается, тема работает в текущей вкладке, предупреждения о прогрессе остаются видимыми.
